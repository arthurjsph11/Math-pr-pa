# Résumé : résoudre une équation du premier degré

<p class="pas-imprime"><BoutonImprimer /> <a href="./equation-premier-degre">← Retour à la leçon</a></p>

::: memo L'image à retenir
**Une équation, c'est une balance en équilibre.
Ce que je fais à un plateau, je le fais à l'autre.**
:::

::: definition
Une **solution** est une valeur de $x$ qui rend l'égalité vraie. Une équation est
**du premier degré** si elle peut s'écrire $ax + b = 0$ avec $a \neq 0$.
:::

::: propriete Les deux règles (elles gardent les mêmes solutions)
1. Ajouter ou soustraire **un même nombre** aux deux membres.
2. Multiplier ou diviser les deux membres par **un même nombre non nul**.

Si $a \neq 0$, l'équation $ax + b = 0$ a une seule solution : $x = -\dfrac{b}{a}$.
:::

::: methode Méthode
Développer, réduire → les $x$ d'un côté → les nombres de l'autre → diviser par le
nombre devant $x$ → **vérifier** → conclure.
:::

**Exemple** : $5x - 3 = 2x + 9 \;\Rightarrow\; 3x - 3 = 9 \;\Rightarrow\; 3x = 12 \;\Rightarrow\; x = 4$.
Vérification : $5 \times 4 - 3 = 17$ et $2 \times 4 + 9 = 17$ ✓.

::: erreur Les pièges
- $3x = 12$ : on **divise** par 3 ($x = 4$), on ne soustrait pas.
- $-2x = 6$ : on divise par $-2$, **avec le signe** ($x = -3$).
- $2(x + 3) = 2x + 6$, pas $2x + 3$.
:::

::: application À quoi ça sert
Résistance d'une LED : $5 = 2 + 0{,}020\,R \Rightarrow R = 150\ \Omega$.
:::
