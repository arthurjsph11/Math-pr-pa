# Exercices sur le second degré

Trois niveaux, 16 exercices. Prends ton temps : il n'y a pas de chronomètre.

::: methode Comment ça marche
1. **Cherche sur ton brouillon** (ou ta page blanche) avant de taper quoi que ce soit.
2. **Tape ta réponse** dans l'encadré (clavier maths à l'écran sur tablette), puis **Vérifier ma réponse**.
3. **Bloqué ?** Indice 1, puis indice 2, puis la solution complète.
4. **🎲 Nouvel exercice** : la même question avec d'autres nombres. Refais-la jusqu'à la réussir sans indice.
5. Chaque exercice raté va dans **[ton carnet d'erreurs](../../carnet-erreurs)**.
:::

Une équation du second degré a souvent **deux** solutions. L'encadré n'accepte qu'une réponse :
l'énoncé te dit laquelle donner (la plus petite, l'autre que celle connue…). Écris-la sous la forme **x = valeur**,
avec une fraction irréductible si besoin (`-7/3`). Le corrigé, lui, donne toujours les deux.
