## Formules dans le texte

Une formule dans une phrase : l'identité remarquable $(a+b)^2 = a^2 + 2ab + b^2$
s'affiche au milieu du texte. La loi d'Ohm s'écrit $U = R \times I$.

## Formules centrées

$$
x = \frac{-b - \sqrt{\Delta}}{2a} \qquad \text{et} \qquad x = \frac{-b + \sqrt{\Delta}}{2a}
$$

Une formule longue, pour vérifier qu'elle défile sur téléphone au lieu de déborder :

$$
1 + q + q^2 + q^3 + q^4 + q^5 + \dots + q^n = \frac{1 - q^{n+1}}{1 - q} \quad \text{pour } q \neq 1
$$
